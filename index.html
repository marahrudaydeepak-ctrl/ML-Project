About Project

Credential Stuffing Attack Detection Using Gradient Boosting Machine and Isolation Forest

Credential stuffing is an attack where bots replay username and password pairs leaked from other breaches against a login page, hoping users reused them. Because each attempt uses real credentials, simple rate limits and password rules miss much of it.

This project scores login traffic with two models. Isolation Forest learns what normal logins look like without labels and flags outliers, which helps with new attack patterns. Gradient Boosting is trained on labeled attack and benign traffic and is more accurate on known patterns. The hybrid score combines both.

Features used

Attempts per minute, distinct usernames per IP, failed-login ratio, timing regularity, proxy or datacenter IP, and new-device flag.

About this demo

This site runs entirely in your browser. Its scores come from a small formula that imitates the two models so you can explore the interface. To use your own trained models, connect the predict() function in app.js to an API, as described in the README.
